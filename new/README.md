# Chi Status 新版預覽

這個資料夾是 Chi Status 全站重寫的隔離預覽版本，尚未取代根目錄正式網站。

## 預覽方式

部署後開啟 `https://status.chi.qzz.io/new/`。新版讀取上一層的 `../status.json`，並連結共用版面中的 `./actions/` 控制台；不會修改資料收集、告警、Worker 驗證或 Actions 觸發流程。

## 設計原則

- 依 Chi Design System 的 tokens、元件間距、字級階層、圓角、柔和藍紫漸層與淺色優先主題實作。
- 內嵌必要樣式與線性 SVG，避免 CDN、外部字型或圖示服務成為頁面依賴。
- 保留現有狀態資料的欄位與篩選能力，支援搜尋、摘要、詳細資訊、重新整理、每分鐘更新與深色模式。
- 手機導覽、鍵盤焦點、跳至主要內容與減少動態效果均有處理。
